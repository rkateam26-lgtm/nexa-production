# 🚀 NEXA — Plateforme de Fidélisation & CRM par QR Code (V1 Restaurants)

Nexa est une solution SaaS moderne de fidélisation et de relation client pour les restaurants. Les clients n'ont **aucune application à télécharger** : ils scannent simplement un QR code sur leur table pour accumuler des points et débloquer des récompenses. Le restaurateur dispose d'un Dashboard Desktop complet pour gérer ses clients, ses récompenses, ses QR codes et envoyer des notifications push ciblées.

---

## 🌟 Établissement de Démonstration : "LE SAVANE"

- **Client App Mobile** : Interface smartphone ultra-moderne avec jauge de points (+10 pts/scan), catalogue de récompenses déblocables, Pass QR Code pour la caisse et notifications d'offres flash.
- **Restaurateur SaaS Dashboard** : Vue d'ensemble avec KPIs, CRM clients, gestionnaire de récompenses, générateur d'affiches QR Code imprimables, et outil d'envoi de campagnes push.
- **Mode Double Écran En Direct** : Visualisation côte à côte avec synchronisation bidirectionnelle des données en temps réel.

---

## 🛠️ Technologies Utilisées

- **Structure** : HTML5 sémantique
- **Style** : Vanilla CSS3 (Design System avec typographies Google Fonts *Outfit* & *Plus Jakarta Sans*)
- **Logique** : JavaScript ES6 réactif (State réactif synchronisé)
- **Icônes & Libs** : Lucide Icons, Chart.js, Canvas Confetti
